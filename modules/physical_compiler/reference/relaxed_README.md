# Pinned relaxed-router comparison

`relaxed_reference.py` compiles and executes the original `IndependentSetRouter`
methods from MQT QMAP commit `cd8ec9131f99d93ce1601c9a1dcad5c9e09ce31d`.
It also executes the existing original rearrangement generator for three
two-atom order reversals. No Python translation supplies the expected results.

## Extraction and evidence

The harness verifies the SHA-256 fingerprints of the original source files.
It mechanically extracts the complete router class and all router method
bodies. Private access labels become public so the adapter can observe the
original pair classification and mover order; the unrelated JSON serialization
macro becomes a no-op. Method bodies are unchanged.

The C++ adapter provides a regular coordinate lattice, site identities, the
same Euclidean endpoint distance convention, and JSON I/O. It does not make
compatibility, graph, routing, or merging decisions. The coordinate lattice is
only an adapter for the router's endpoint input; it does not claim a realized
device geometry. Fixtures use nonnegative integer nanometres, matching the
upstream `size_t` coordinates.

The router output includes:

- Distance-sorted mover IDs, including the upstream descending-ID tie break.
- Original pair status and optional merge cost.
- Original strict groups and final relaxed groups.

Normalized merge costs are divided by 1000, just like coordinates. These costs
have the dimensions of length and represent a cubed-time proxy; they are not
durations in microseconds. Scaling every coordinate by the same positive
constant leaves the merge criterion unchanged. The default `preferSplit` is
1.0. A failed merge keeps the existing strict group.

Group order is preserved. Members within each group are sorted in the oracle,
because upstream commits merged atoms through an `unordered_map`. Raw output
in the temporary report preserves the exact order returned by the binary.

## Fixtures and scope

`relaxed_fixtures.json` covers strict compatibility, X/Y/XY reversals, low-cost
merges, high-offset rejection, zero and increased `preferSplit`, hard
split/merge conflicts, and accumulation of costs for a two-atom donor group.
An asymmetric reversal also exercises the recipient's maximum-distance
increase after the lower-distance donor's merge was rejected.
`relaxed_expected.json` is generated by the original C++ router.

`relaxed_staging_fixtures.json` provides regular storage and paired gate SLMs
for two-atom X/Y/XY reversals. `relaxed_staging_expected.json` is generated by
the original C++ code generator with the existing `adapter_*.cpp`. It is
separate from the nine strict oracles and from the recorded unsafe sparse
release case.

This checks supplied routing inputs and supplied rearrangement batches.
It does not execute upstream scheduling or placement, nor prove hardware
capacity, occupied SLM safety, empty AOD intersection safety, or arbitrary
batch realizability. NADiT's separate constructive admission rules and
explicit-grid legality tests cover those constraints. Comparing raw routing
uses no NADiT admission callback.

## Running

From `modules/physical_compiler`, with an independently installed C++20
compiler:

```powershell
python -m reference.relaxed_reference `
  --cache-dir "$env:TEMP/nadit-qmap-cd8ec913" `
  --cxx "/absolute/path/to/zig.exe" `
  --output "/absolute/path/to/relaxed-results.json" `
  --expected-output reference/relaxed_expected.json `
  --staging-expected-output reference/relaxed_staging_expected.json
```

`--build-only` compiles both adapters without executing any fixtures.
The temporary report records inputs, raw binary output, source fingerprints,
translation-unit fingerprints, and actual compiler commands. Checked-in
oracles omit machine-specific build paths.

To compare the pure NADiT router against the generated oracle:

```powershell
python -m reference.relaxed_candidate `
  --output "/absolute/path/to/relaxed-candidate.json" `
  --expected reference/relaxed_expected.json
```

This uses unrestricted line capacity and a 1 nm minimum spacing, below all
distinct fixture line separations. The relaxed call supplies no admission
callback. A separate call rejects every merge to expose the strict initial
groups. Pair status, proxy cost, group membership, and group order are compared.

The MIT attribution and primary source links are in [README.md](README.md).
